# Audio Loader Encore 1.6.3

Rebuilt the **Microphone** muffling toggle (Effects tab).

- Before, it looked for a "muted" flag that Steam does not have, so it most likely never worked.
- Now the music is muffled for a moment (1.5 seconds) whenever the microphone is switched on or off, muted, or its volume changes. It can never stay muffled by itself.
- If it still does nothing on your Deck: send the Decky log line that starts with "Low-pass filter: reading the microphone" or "could not read".
