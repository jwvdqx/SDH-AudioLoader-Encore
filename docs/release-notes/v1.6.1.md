## Audio Loader Encore v1.6.1

### Now Playing notification control

The Music → Playback switch is now named **Show Now Playing Notifications**. Turn it off to suppress Encore's small popup when a new music pack or Steam soundtrack track starts.

This affects only those Now Playing popups. The persistent Now Playing card (including progress and Up Next) stays visible, and all other Steam/Decky notifications continue to work normally.

Your existing preference is preserved during the upgrade.

Install from Decky: Developer mode → Install Plugin from URL →
`https://github.com/jwvdqx/SDH-AudioLoader-Encore/releases/latest/download/Audio-Loader-Encore.zip`
