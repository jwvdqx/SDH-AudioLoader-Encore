# SDH Audio Loader Encore 2.0.6

### Fixed
- **Long songs restarted from the beginning after Desktop Mode, a game or sleep** (Continuous Playback).
  Steam's local file server does not let a player jump far into a file it has not loaded yet. A long file
  (like an hour-long mix) loads bit by bit, so the jump to the remembered second quietly failed and the
  song played from the start. After a few seconds that new "start" replaced the remembered place. Checked
  in Chromium with a 1-hour file and a server like Steam's: before, it played from 0:01; now it carries on
  at 30:00. How it works now:
  - The jump is checked. The player stays silent until it is at the right second, and the jump is tried
    again while more of the file loads.
  - If the server never allows the jump (after about 4 seconds), the whole file is loaded into memory,
    where a player can jump anywhere. That memory is freed when the song is stopped.
  - While the jump is on its way, the remembered place stays the remembered second, so it is never lost.
  - The Decky log says how each resume went (carried on at X s of Y s, loaded the whole file, or gave up
    after 12 seconds and played from where it was).
