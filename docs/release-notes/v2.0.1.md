# SDH Audio Loader Encore 2.0.1

### Fixed
- **Music did not come back after sleep.** The browser's media session sends separate Play and Pause commands,
  but Encore treated both as the Play/Pause toggle. A pause the system sends while the Deck goes to sleep was
  remembered as "paused on purpose", so waking up did not restart the music (the log said "another plugin
  paused it on purpose"). Play now only plays, Pause only pauses, and the Play/Pause key still toggles
  (Media Play and Media Pause keys are explicit too). A pause that came through the media session no longer
  survives a sleep; a pause with the button or the key does.
- **The music guard could switch itself off.** After sleep, `play()` could stay unanswered forever, which kept
  the guard busy until Steam restarted. It now waits at most 4 seconds.
- **Waking with Continuous Playback could end up silent.** The old player was reused if its clock moved, even
  when its sound output was dead. After waking a new player is always built, and it carries on from the
  remembered place.
- **Continuous Playback started from the beginning.** On waking, the place read from a player that sleep had
  reset to second 0 replaced the good remembered place. A reset player no longer overwrites it.
- **A remembered place at the very end of a song** restarted that song from the beginning. In a shuffle mode the
  next music now takes over (Repeat plays the song again).
- **A frozen screen was mistaken for sleep.** A long gap between two checks counted as sleep, even when the music
  had kept playing. That no longer restarts the music.
- **A music file the player cannot decode** left the music silent for good. In a shuffle mode the guard now
  moves on to the next music.
- **Notification sounds.** "Lower Music For: Notifications" and "Muffled Music: Pop-ups and Notifications"
  now share one list. The chat and friends sounds (`steam_at_mention`, `steam_chatroom_notification`,
  `ui_steam_message_old_smooth`, `ui_steam_smoother_friend_join`, `ui_steam_smoother_friend_online`) were
  missing from it, and the muffling listed the chat sound with a wrong file extension.
- **Lowering the music no longer dips every new song** when Encore's own Now Playing notification shows.

### Added
- Tests for the sleep/wake and resume fixes and for the notification sound list.
