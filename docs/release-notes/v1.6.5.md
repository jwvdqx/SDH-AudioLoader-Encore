# Audio Loader Encore 1.6.5

Fix for music that seemed to loop by itself in the Shuffle and Smart Shuffle modes.

- **Music by Time of Day:** its pack used to be picked again on every replay, so the same music repeated all morning, afternoon or night. Now it plays once when the part of the day starts (or when the Deck starts), then the shuffle goes on. The Up next line and Skip follow the same rule.
- If the music ended and the next one did not start, the automatic repair restarted the same music. In a shuffle mode it now starts the next music.
