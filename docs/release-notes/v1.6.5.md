# Audio Loader Encore 1.6.5

Everything since 1.6.1, in one release.

**Fixed**
- Music that seemed to loop by itself in Shuffle and Smart Shuffle:
  - **Music by Time of Day** used to pick its pack again on every replay. Now it plays once when a part of the day starts (or when the Deck starts), then the shuffle goes on. The Up next line and Skip follow the same rule.
  - If the music ended and the next one did not start, the automatic repair restarted the same music. In a shuffle mode it now starts the next music.
- **Microphone** muffling toggle rebuilt. It used to look for a "muted" flag that Steam does not have, so it most likely never worked. Now the music is muffled for 1.5 seconds whenever the microphone is switched on or off, muted, or its volume changes. It cannot get stuck.
- Steam Music: a soundtrack with no playable tracks no longer leaves an empty folder behind.

**Faster**
- Opening a pack list no longer scans all your Steam soundtrack folders every time (at most every 30 seconds; **Scan Again** scans right away).

**Project**
- More automatic tests, run by every build.

If the Microphone toggle still does nothing, send the Decky log line that starts with "Low-pass filter: reading the microphone" or "could not read".
