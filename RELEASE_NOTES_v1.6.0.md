## Audio Loader Encore v1.6.0

**Menu player**
- **Progress bar** with time played and length.
- **Up next**: the next music is chosen ahead of time, so what you see is what plays, when the music ends and when you press Skip.
- **Play Mode button** on the Now Playing card: **Repeat → Shuffle → Smart Shuffle**.
  - **Shuffle**: purely random.
  - **Smart Shuffle**: avoids recent packs and series (Variety) and plays favorites more often.

**Changed**
- **New Music Every Replay** is now **Play Mode** (Rotation group). If you had it on, you start in Smart Shuffle, which behaves exactly like before.
- Skip follows the play mode.

Also in this release: the **Volume** and **Microphone** low-pass toggles from 1.5.1 (Microphone is still experimental).

Install from Decky: Developer mode → Install Plugin from URL →
`https://github.com/jwvdqx/SDH-AudioLoader-Encore/releases/latest/download/Audio-Loader-Encore.zip`
